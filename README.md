# Punt Wars 2026

Late-1990s dashboard for a season-long bet:

**Average gross yards per punt of the top two Australian NFL punters vs the top two American NFL punters (2026 regular season).**

Live on GitHub Pages after deploy.

Open `index.html` locally if you want. Week boxes save in the browser.

Ireland (Whelan) and Belgium-born Waitman are listed but excluded from the USA side of the bet.
